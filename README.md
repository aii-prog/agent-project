## 这是什么

面向制造企业工程师与采购的 7×24 售前咨询 Agent。本仓库用虚构品牌 **KANAGU FA** 和虚构型号，重建了我作为 AI 产品经理主导的项目，展示 Agent 帮客户完成了什么，以及我负责的设计。

页面分三部分：

| 标签页 | 内容 |
| --- | --- |
| 任务演示 | 5 个可逐步播放的场景。左侧是客户看到的对话，右侧是 Agent 每一步的执行轨迹 |
| 我的设计 | 对话主流程、意图类型与二级意图、Skill 触发边界与工具调用规则、SOP“理想回答”标准、架构演进 |
| 评测与成果 | 四维评估框架、断点 + 端到端评测、Bad Case 归因顺序、项目指标、我负责的部分 |

## 演示场景

1. **选型推荐**：参数不全 → 工具结果不满足 → 回到 Skill 反问参数 → 按 SOP 给出可下单型号
2. **批量报价**：多轮指代、复合意图并行调用工具；无自动价格时生成询价线索交给营业
3. **竞品替换**：只做规格对照，明确写出差异风险；需要看图纸时生成技术咨询工单
4. **短路径分流**：闲聊引导、需求不明时给选项澄清、命中 QA 对直接回答
5. **转人工与情绪**：近 5 轮转人工诉求 / 负面情绪累计 3 次才转人工，转接时附交接摘要

## 关键设计

- **QA 对前置**：答案固定的高频问题直接回答，稳定、低成本、低时延
- **5 类意图分流**：转人工 / 闲聊 / 有效咨询 / 需求不明 / 情绪宣泄，只有有效咨询进入 Skill
- **Agent + 可插拔 Skill**：产品参数、报价采购、竞品对比、售后支持，各自定义触发边界与工具串并行规则
- **工具结果校验回环**：工具结果不满足需求时回到 Skill 重新决策
- **转人工计数规则**：先安抚并尝试解决，达到阈值再转人工
